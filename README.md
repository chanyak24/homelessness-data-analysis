# Homelessness Trends Analysis in Australia

## Project Overview

This project analyzes homelessness trends in Australia using multiple datasets, including homelessness statistics, COVID-19 notification rates, and job vacancy data. The objective was to identify economic and social factors contributing to homelessness across Australian states.

---

## Objectives

* Analyze homelessness trends across Australian states
* Explore relationships between economic conditions and housing insecurity
* Evaluate the impact of COVID-19 and job vacancies on homelessness

---

## Data Sources

* Australian Bureau of Statistics (ABS)
* National Notifiable Diseases Surveillance System (NNDSS)

Datasets used:

* Homelessness statistics
* Job vacancies
* COVID-19 notification rates

---

## Tools & Technologies

* R
* tidyverse
* dplyr
* ggplot2
* readxl

---

## Data Processing

The analysis involved:

* Cleaning and transforming raw datasets
* Standardizing state-level data
* Merging multiple datasets for comparative analysis
* Calculating percentage changes and trends
* Conducting exploratory data analysis (EDA)

---

## Key Insights

* Several Australian states experienced increased homelessness between 2016 and 2021
* Economic conditions and employment trends may influence housing insecurity
* COVID-19 created uneven impacts across states and communities
